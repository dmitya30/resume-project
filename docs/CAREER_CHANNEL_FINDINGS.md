## 6. Сопроводительные сообщения

Дословный пятистрочный шаблон «Богатого Карьериста» в JSON отсутствует: ID 405 и ID 440 содержат только описание или изображение без текста.

В ID 774 приведено длинное письмо с ролью, достижением, задачей компании, предполагаемой пользой и предложением созвона.

Решение проекта: использовать два коротких варианта как собственные гипотезы:

- `message_role_match` - соответствие требованиям роли;
- `message_case` - конкретная задача работодателя и релевантный подтвержденный кейс.

Это не называется полноценным A/B-тестом, поскольку вакансии и условия не идентичны. По возможности меняется только один существенный элемент сообщения.

Выгрузка не подтверждает конкретный формат файла, шрифт, размер, плотность ключевых слов или эффективность отдельного ATS-валидатора.

## 9. Отклоненные и недоказанные рекомендации

- Массовые отклики через HH: уже проверены примерно на 330 откликах без практической конверсии.
- Чужие нормативы откликов, интервью и срока поиска.
- Заявления о почти гарантированном трудоустройстве.
- Преувеличение или фабрикация опыта.
- Автоматическое удаление блока «Обо мне».
- Автоматическое объединение мест работы.
- Обращение сразу к пяти сотрудникам одной компании.
- Признание 48 часов доказанным универсальным порогом.
- Покупка карьерных услуг без независимой проверки условий, цены, альтернатив и результатов.

## 10. Принятые рабочие гипотезы

1. Свежие вакансии могут давать больше ответов; проверяется по возрастным категориям.
2. Прямой письменный контакт может быть эффективнее отклика через агрегатор.
3. Персонализация через требования роли и персонализация через релевантный кейс могут давать разную конверсию.
4. Узкое резюме под одно из трех направлений лучше смешанного позиционирования.
5. Если ответы есть, но интервью не продолжаются, проблема может находиться на следующем этапе, а не в резюме.
6. Банк правдивых STAR-кейсов может улучшить подготовку к интервью.

Гипотезы считаются рабочими только после проверки собственными наблюдениями. Отсутствие данных не превращается в отрицательный вывод.
