# Калибровка оценки вакансий

## Назначение

Документ фиксирует результаты первой калибровки OpenRouter scoring v1 и требования к scoring v2.

Калибровочный workflow:

```text
workflows/03-score-found-vacancies.json
```

## Исходная выборка

На момент повторной обработки Data Table содержала 160 вакансий:

- `found`: 86;
- `filtered`: 72;
- `parse_failed`: 2.

Жесткими фильтрами было исключено 45 процентов выборки.

Количество причин больше количества отфильтрованных вакансий, поскольку одна вакансия может иметь несколько причин.

## Технический результат

Калибровка выполнена на десяти вакансиях.

Подтверждено:

- все десять ответов завершены;
- `reasoning_tokens=0`;
- ответы соответствуют JSON Schema;
- стоимость одного вызова составила примерно от 0.0001 до 0.00043 доллара;
- выбор варианта резюме в целом работает корректно;
- правило для удаленных вакансий модель поняла.

Первый запрос для вакансии `136352607` был оборван при `max_tokens=1200`.

После увеличения лимита до 2600 и отключения reasoning полный ответ был получен.

## Выявленные проблемы

### Нестабильность критических требований

Для вакансии `136352607`:

- оборванный ответ предполагал score 51;
- повторный полный ответ дал score 80;
- модель одновременно указала отсутствие 1С, Bitrix24, обследования бизнес-процессов и подготовки технических заданий.

Результат 80 завышен. Отсутствие основной обязательной специализации не должно приводить к decision `recommend`.

### Неподтвержденные evidence

Для вакансии `137155325` модель указала написание Bash-скриптов.

Bash не подтвержден в профиле кандидата.

Для вакансии `137196945` модель указала опыт создания AI-агентов.

В профиле подтверждены LLM-интеграции и workflow, но не полноценная разработка AI-агентов.

### Нерелевантные штрафы

Модель периодически добавляла риски за:

- незаконченное высшее образование, когда законченное образование не требовалось;
- английский язык, когда он не был указан;
- отсутствие необязательных или альтернативных технологий.

Scoring v2 должен оценивать только фактические требования конкретной вакансии.

### Противоречие cover_letter_recommended

Для вакансии GetCourse модель вернула:

```text
score=45
decision=reject
cover_letter_recommended=true
```

Это поле больше нельзя принимать напрямую от модели.

Оно должно вычисляться Code JS после окончательного decision.

## Решения для scoring v2

- Добавить `critical_gap` и `critical_gaps`.
- Ограничивать score значением 59 при критическом пробеле.
- Пересчитывать decision в Code JS.
- Пересчитывать `cover_letter_recommended` в Code JS.
- Требовать конкретное подтверждение для каждого evidence.
- Явно отделять прямой опыт от смежного.
- Не штрафовать за требования, отсутствующие в вакансии.
- Не считать optional и alternative требования обязательными.
- Сохранить географическое правило для remote без ограничения региона.
- Для `unspecified` вне Санкт-Петербурга и Мурино снижать `conditions_fit`, но не выполнять автоматический hard reject.

Полный контракт scoring v2 описан в `PROMPTS.md`.

## Результат scoring v2

Scoring v2 прошел контрольный тест и был применен ко всем 86 вакансиям со status `found`.

Итоговое состояние:

- `found`: 0;
- `scored`: 86;
- `filtered`: 72;
- `parse_failed`: 2.

Критические изменения относительно v1:

- текущая дата передается через `$now`;
- модель больше не определяет окончательные score и decision;
- score пересчитывается из `score_breakdown`;
- critical gap ограничивает score значением 59;
- `cover_letter_recommended` рассчитывается Code JS;
- вызов OpenRouter выполняется непосредственно из Code JS;
- используется `$env.OPENROUTER_API_KEY`;
- добавлен compact Scoring Export;
- добавлены минимальные зарплатные пороги;
- salary blocker применяется по известной верхней границе;
- отсутствие зарплаты не является причиной отказа;
- нижняя граница без максимума не является причиной отказа.

После исправления parser и повторной обработки подтверждено 9 вакансий с `salary_below_minimum`.

Следующая калибровка не требуется до появления фактических проблем в новых данных. Следующий этап - ранжирование, подготовка писем и реальные отклики.
